# Detection and Traking

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Um programa que rastreia a bola de basquete no vídeo com OpenCV

---
## 📚 Aprendizados
- Rastreamento e detecção de objetos

## ⚙️ Funcionalidades
- Após selecionar a bola ela ira ser detectada e sua trajetória ira ser acompanhada de demonstrada na tela.


## 🛠️ Stack
- Python
- OpenCV

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/VitorDCqwe/Detection-and-Traking
```

2. Abra o arquivo e execute no teminal.
